# Редактор текста на Taiga UI Editor

Готовая версия редактора на `@taiga-ui/editor` 5.7.0. Исходный редактор из чата «Первая версия редактора текста» не изменён.

## Что находится в репозитории

- `index.html` — готовое приложение; JavaScript и стили встроены в файл.
- `assets/` — иконки Taiga и SVG из исходного редактора. Папка обязательна.
- `source/` — исходники Angular, зависимости и файл блокировки версий.
- `.github/workflows/pages.yml` — публикация готовой версии в GitHub Pages.
- `LIMITATIONS.md` — поддерживаемые функции и известные ограничения.

## Загрузить на GitHub

1. Создайте отдельный репозиторий для этой версии редактора.
2. Распакуйте архив и загрузите **содержимое** папки `github-taiga-editor` в корень репозитория. `index.html` должен находиться в корне, рядом с `assets` и `source`.
3. При загрузке через браузер проверьте, что добавилась скрытая папка `.github` с файлом `workflows/pages.yml`.
4. Откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
5. В **Actions → Publish editor to GitHub Pages** запустите **Run workflow**. Далее публикация выполняется после коммитов в `main` или `master`.
6. Ссылка появится в успешном запуске workflow и в **Settings → Pages**.

Репозиторий и публикация в этом комплекте не создавались. Готовая версия работает и на проектном адресе вида `https://USERNAME.github.io/REPOSITORY/`: пути к ресурсам относительные. Workflow публикует только приложение и иконки; исходники остаются обычными файлами репозитория.

Документация GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Локальный просмотр готовой версии

Из корня репозитория:

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

Откройте http://localhost:4180. Остановка — Ctrl+C. Для готовой версии Node.js и Angular не нужны. Прямое открытие `index.html` через `file://` не проверялось; используйте HTTP-сервер.

## Изменить исходники и обновить готовую версию

Понадобятся Node.js 24 и pnpm 11.25.0.

```sh
cd source
pnpm install --frozen-lockfile
pnpm run build:github
```

Команда собирает Angular и обновляет `../index.html` и `../assets`. После изменения исходников нужно закоммитить и исходники, и обновлённую готовую сборку. GitHub Actions публикует уже собранные файлы и не собирает Angular заново.

Режим разработки:

```sh
cd source
pnpm start
```

## Хранение данных

Заголовок, содержимое и вложения сохраняются в localStorage текущего браузера. После смены домена, порта или браузера черновик автоматически не переносится. Большие вложения могут превысить квоту хранилища. Серверного хранения, авторизации и совместного редактирования нет.

Иконки и стили адаптированы под исходный прототип. Действия редактирования выполняют готовые компоненты Taiga; оболочка отвечает за загрузку файлов, сохранение, счётчик и размещение панели.
