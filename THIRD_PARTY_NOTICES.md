# Сторонние материалы

Приложение использует Angular, Taiga UI, Taiga UI Editor, Tiptap и зависимости из `source/package.json` и `source/pnpm-lock.yaml`.

Лицензии установленных пакетов необходимо сохранять при распространении. Angular формирует файл уведомлений при сборке; он включён в этот комплект как `THIRD_PARTY_LICENSES.txt`.

SVG в `assets/editor-icons` взяты из исходного прототипа пользователя. Права на эти материалы не переоформлялись; отдельная открытая лицензия на них этим комплектом не устанавливается.
